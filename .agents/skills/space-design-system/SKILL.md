# Space design system

Read `docs/design/design-system.md` and the relevant product flow. Prefer whitespace, typography, and alignment over containers or decoration. Credentials are primary content; an empty vault shows only essential orientation and Create. Use monochrome semantic tokens, one restrained radius scale, few borders, and subtle state-transition motion with reduced-motion fallbacks. Preserve visible keyboard focus, semantic names, 44px touch targets on iOS, zoom/reflow, contrast, screen-reader order, and private-value concealment. Test empty, loading, error, locked, populated, and long-content states.
